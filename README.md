# CyberGuard Bot — Cybersecurity Awareness Chatbot

This is a chatbot I built using Windows Forms and C#. It teaches users about cybersecurity topics through a simple conversation.


## What the app does

- Plays a voice greeting when you open it
- Asks for your name and uses it throughout the chat
- Answers questions about passwords, phishing, malware, privacy, 2FA, and safe browsing
- Gives different responses each time so it doesn't get repetitive
- Detects if you're worried or confused and responds accordingly
- Remembers your name and what topic you're interested in
- You can click the sidebar buttons to quickly ask about a topic



## How to run it

1. Open Visual Studio 2022
2. Clone or download this repo
3. Open the `.sln` file
4. Make sure `greeting.wav` is inside the `Media` folder
5. Press **F5** to run



## Requirements

- Windows 10
- Visual Studio 2022
- .NET 8



## Topics covered

- Passwords
- Phishing and scams
- Malware
- Privacy
